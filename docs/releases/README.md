# Release records

This folder holds one record per release, named `YYYY-MM-DD.md`. Each record is a filled-in copy of the [release checklist](../sop.md#release-checklist), and it's the proof that the release was checked.

> **Note:** The first record, `2026-11-03.md`, follows an earlier version of the checklist, before the release audit was added. Later records use the current checklist.
