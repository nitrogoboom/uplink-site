## C. Accessibility by hand: WCAG 2.0 AA

Checked by script (Chromium, 1440×900, every page in the sitemap plus soon and the 404):

- [x] 2.4.1 Skip link: the first Tab on every page is "Skip to content", and the Tab after it lands inside `<main>` (checked on Home, Services, Contact).
- [x] 2.1.2 / dialogs: Settings, Book a call and Shortcuts each open from the keyboard, focus goes inside, Esc closes, focus returns to the button. `?` opens Shortcuts.
- [x] 2.4.2 Every page has a title, and no two are the same.
- [x] 3.1.1 `lang="en-CA"` on every page.
- [x] 1.3.1 One `h1` per page and no skipped heading levels; no duplicate ids; every form field has a label.
- [x] 1.1.1 Every `<img>` has `alt`; every drawing in `<main>` has a label. **Fixed during this run:** SVGO was stripping `role="img"` from every drawing (`scripts/svgo-config.mjs` now keeps it), so some screen readers could have read the drawings as groups of shapes instead of one picture.
- [x] 1.4.4 200% text: no clipped, overlapping or unreachable text, no sideways scroll (`verify_text.py`).
