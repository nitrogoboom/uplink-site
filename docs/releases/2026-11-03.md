## Second pass, same evening: the release audit

The first release audit run (`npm run release-audit`, `tools/audit.py`) on branch `prod-ready`, built and served locally. It replaces most of B and C above; the checklist in `docs/sop.md` is now arranged around it.

**Result: every part passes**, after the fixes below. 20 pages each time.

- [x] **Browsers:** Chromium, Firefox and WebKit at 1440, emulated iPhone 15 (WebKit) and Pixel 7 (Chromium): no script errors, no CSP blocks, no sideways scroll.
- [x] **Keyboard:** every page tabbed through; focus visible at every stop, never off screen, never stuck. Settings, Book a call and Shortcuts dialogs: open from the keyboard, Esc closes, focus returns.
- [x] **Screen reader:** every page read with Guidepup's Virtual Screen Reader; no run-on link names, no link name going to two pages.
- [x] **Motion:** with Reduce Motion on, nothing moves on any page. With it off, Home (hero) and the footer map loop; the pause button stops every one of them.
- [x] **Forms:** contact, Book a call and newsletter, sent empty and with a bad email: each problem field has its message in words, tied to the field (`aria-describedby`), and focus goes to the first one.
- [ ] **HTML:** an earlier run found one real error (each page's own script came after `</html>`; fixed). The final run was refused by W3C ("too many requests" after a day of runs). Rerun `npm run release-audit -- --only html`.
- [x] `npm run ci` (check, lint, build, browser check) and `verify_text.py` (200% text) pass on the final build.

**Fixed during the audit:**
- **Run-on link names on most pages.** Cards on Services, Work, Contact, each service page's "Where we've done this" and the footer read as one string ("Support Managed help desk Real people who…"). Now: "Managed help desk. Real people who…", as Home already did (`<Pause />` after the title, category chips hidden from screen readers, " · " as a comma). The project card is now one component (`src/components/work/ProjectCard.astro`) instead of three copies.
- **Footer tabs and social links** read "Services 7 links", "LinkedIn/company/uplinkit"; now "Services. 7 links", "LinkedIn. /company/uplinkit".
- **About:** the profile card was read before the page heading (and on phones, where the text shows first, read second). The text now comes first in the HTML; the grid keeps the card on the left on screen. The card is an `aside` named "Uplink at a glance". The step numbers (1–4) were read on their own before each heading; the list already numbers them, so they're hidden from screen readers.
- **Contact:** the reply-time ring read "1 day, Reply to new messages"; now "Reply to new messages. 1 day".
- **Scripts after `</html>`:** Home, Work, Contact and soon put their own script outside the layout. Now inside `<body>` through `<Fragment slot="scripts">` (`Base.astro`).
- **A bug the new pauses caused, caught before it shipped:** a pause inside the footer's sideways-scrolling tab row escaped the row and made every page 280px too wide on phones. `.fc-tile` and `.fc-wall-item` now have `position: relative`.

Nothing moved on screen: live and local screenshots of About, Contact, Services, Work and a service page are identical at 390, 820 and 1440 wide, apart from animation frames inside the drawings.

**Still for a person:** section C of the new checklist in `docs/sop.md` (real iPhone and Android, a 5-minute NVDA listen, the judgement checks), and D.
